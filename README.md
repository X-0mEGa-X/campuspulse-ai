# CampusPulse AI

Учебный помощник для кейса № 2 Build with AI / GDG Astana. Отвечает по конспектам и фотографиям, получает задания из GitHub и распределяет работу до дедлайнов.

Команда: Адилет Бердыбеков, Булатов Артур, Зайниддин Айбек.

[Презентация](output/presentation/CampusPulse-AI.pptx) · [Архитектура](docs/ARCHITECTURE.md) · [Проверки](docs/VERIFICATION.md)

## Возможности

- До 10 отдельных чатов со своими сообщениями, файлами, задачами и планом. Доступны переименование, очистка, удаление и возврат последнего удалённого чата.
- Вопросы по PDF с текстом, DOCX, TXT, Markdown и фотографиям JPEG, PNG, WebP.
- Получение открытых Issues и README публичных репозиториев GitHub с указанием источника.
- Учебный план с дневным лимитом, дедлайнами и часовым поясом. Экспорт в календарь через `.ics`.
- Журнал вызовов инструментов: аргументы, результаты и время выполнения.

Gemini выбирает инструменты, MCP получает данные и рассчитывает расписание, Streamlit показывает результат. Локальная версия использует Gemini Developer API. Для ключей бесплатного тарифа действуют квоты провайдера.

## Запуск

Python 3.12. В Windows приложение запускается через `START-CampusPulse.cmd`. Скрипт создаёт виртуальное окружение и устанавливает зависимости при необходимости. Адрес интерфейса: <http://127.0.0.1:8501>.

Ручной запуск из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Для чата используется `GEMINI_API_KEY` в локальном `.env`. Ключ выдаёт [Google AI Studio](https://aistudio.google.com/api-keys). Без ключа доступен режим «Только инструменты»: задачи, планировщик и MCP. Файл `.env` исключён из Git и архива проекта.

Модель задаёт `GEMINI_MODEL`, по умолчанию `gemini-3.5-flash-lite`. `GEMINI_API_ENDPOINT=standard` использует основной endpoint Google, `mtls` — официальный альтернативный endpoint. Проверка TLS включена в обоих случаях.

## Работа с приложением

«Новый чат» создаёт отдельную тему. Список «Текущий чат» переключает темы. «Очистить чат» удаляет переписку, сохраняя задачи, вложения и план. Переименование и удаление находятся в меню «Ещё».

Файлы прикрепляются кнопкой `+` у сообщения или в разделе «Материалы». Ответы и журнал остаются в чате. Расписание и скачивание `.ics` находятся в разделе «Учебный план» выбранного чата. Общие настройки модели, часового пояса и учебного бюджета доступны слева в «Настройках агента».

## MCP и облачный адаптер

Сервер `campuspulse.mcp_server` предоставляет шесть инструментов: текущее время, расчёт дедлайна, GitHub Issues, GitHub README, поиск по материалам и планирование недели. Транспорт — stdio, конфигурация — `mcp.json`. Инструменты читают данные и выполняют расчёты, без записи в GitHub или календарь.

```powershell
.\.venv\Scripts\python.exe -m campuspulse.mcp_server
```

Для Vertex AI Agent Engine подготовлены сериализуемый агент, `scripts/deploy.py` с `ReasoningEngine.create` и клиент удалённого API. Параметры развёртывания проверены через `--dry-run`. **Agent Engine не развёрнут, удалённый API недоступен.** В этой версии работает локальный интерфейс, публичного веб-сайта нет.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/smoke_local.py --output tmp/live-check.json
```

Последняя команда обращается к Gemini и GitHub и расходует квоту API. [Протокол проверки](docs/VERIFICATION.md) отделяет автоматические тесты от фактических сетевых запросов.

## Ограничения

- Чаты хранятся в памяти сессии вкладки. Закрытие или полная перезагрузка страницы, а также перезапуск сервера могут сбросить данные. В каждом чате сохраняются последние 100 сообщений, модели передаются последние 10.
- До 30 задач и 5 вложений на чат, по 5 МБ на файл. Общий лимит вложений — 10 МБ, фотографий — 3. Фото ограничены 20 мегапикселями и 10 000 пикселями по стороне.
- Из документа читаются первые 12 000 символов, из PDF — не более 40 страниц. Сканированные страницы анализируются как отдельные фотографии. HEIC, PPTX и старый формат DOC не поддерживаются.
- Поиск по тексту использует ключевые слова. Распознавание фотографий выполняет модель и может содержать ошибки.
- При запросе текст и фотографии передаются Google. Условия использования данных и квоты зависят от тарифа API.
- План не учитывает расписание пар и события внешнего календаря автоматически. Неизвестные сроки не подменяются датами. Если оценка длительности отсутствует, применяется отмеченное допущение в 60 минут.
- GitHub ограничивает частоту запросов. За один запрос обрабатывается первая страница API и до 30 открытых Issues.
