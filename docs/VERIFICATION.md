Реальный журнал нового прогона: [live-run.json](live-run.json). Скрипт теперь возвращает ошибку, если обязательный инструмент отсутствует, любой вызов неуспешен или план не распределил ожидаемые 120 минут. Успешный текст модели сам по себе больше не считается успешной интеграционной проверкой.

В live-тесте задачи и краткий конспект обозначены как тестовые входные данные; README действительно получен с GitHub. Сохранённая запись не выдаётся за ответ на новый запрос. Анонимные квоты GitHub и бесплатные квоты Gemini по-прежнему могут ограничивать следующие запросы.

Скриншоты этой проверки: [расписание](images/plan.png), [чат](images/agent.png), [MCP-вызовы](images/trace.png). Автотест протокола использует управляемую модель и настоящий MCP; он не заменяет live-тест Gemini.

У модели обнаружена склонность ошибаться в днях недели при пересказе календаря. В инструкции запрещено дублировать даты расписания: UI строит таблицу и ICS непосредственно из результата планировщика. Новая live-проверка вернула краткое резюме без ошибочных дней недели. Это не доказательство отсутствия всех возможных ошибок модели.

Полное соответствие кейсу № 2 требует реального развёртывания Agent Engine и успешного remote smoke. Бесплатный локальный Gemini не заменяет этот критерий. Проект организаторов с активным биллингом позволит выполнить подготовленные команды без подключения личной карты.
